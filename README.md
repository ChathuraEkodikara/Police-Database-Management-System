This program manages crime records through a command-line interface. It allows users to input, store, and retrieve crime data, generate reports based on National Identity Card (NIC) numbers, and analyze crime records. 
Users can input details like NIC, age, police station, date, name, and crime type. The program checks for existing NICs to avoid duplicates and provides options to append additional crime details. 
It saves records to a file and generates reports for specific NICs. Additionally, users can analyze crimes by age group, police station, or crime type. 
The program follows a menu-driven approach for user interaction, facilitating efficient crime data management and analysis.
